Featured: gene fusion machine learning algorithm

  • Supervised the lead scientist and co-developed a random-forest ensemble that combines multiple RNA-seq fusion callers to classify true gene fusions from RNA-seq.
  • Features included whether each caller detected the fusion, coverage balance on each side of the breakpoint, and the number of reads crossing the breakpoint.
  • Built in R with randomForest and tuned with caret, using a hyperparameter results table and F1 scoring. Trained on calls confirmed by manual review, PCR, Sanger sequencing, Archer, FISH, and cytogenetics data.
  • Validated by 10-fold cross-validation on 598 fusion calls. It outperformed a simple "n of five callers agree" rule, most of all in specificity.
  • Feature importance showed Kallisto and pizzly contributed nothing, so the caller could be dropped to save compute.

Machine learning in production assays

  • Integrated machine learning into MSI, CNV and fusion pipelines to increase accuracy.
  • Developed an ensemble CNV algorithm for heme NGS that combines CNVkit and PureCN calls, with thresholds tuned against FISH, reaching 93 to 99% chromosome-level accuracy for monosomy 7 and trisomy 8 and 12.
  • Improved MSI detection with models trained and validated on NGS data against orthogonal truth.
  • Launched multiple AI-enhanced NGS assays and liquid biopsy platforms, with the pipelines and LIMS integrated end to end.
  • Built a proprietary Genomic ID algorithm that identifies each patient sample, alongside high-sensitivity tumor-only variant callers.
